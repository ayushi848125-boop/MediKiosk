# MediKiosk

## AI-Powered Multilingual Patient Case-Taking Software

MediKiosk is an AI-powered clinical intake platform designed to collect and structure patient information before doctor consultation.

It uses voice/text interaction, adaptive questioning, OCR, clinical information extraction and AI-assisted summarization to convert patient responses into structured, doctor-ready clinical histories.

## Problem

Manual patient history-taking can be time-consuming and may result in incomplete or unstructured information.

Patients may also face language and communication barriers while describing their symptoms and medical history.

## Our Solution

MediKiosk provides a conversational patient intake system that:

- Collects patient symptoms and medical history
- Supports voice and text interaction
- Uses adaptive questioning
- Converts speech into text
- Extracts relevant clinical information
- Generates a structured patient history
- Creates an AI-assisted clinical summary
- Provides a doctor-side dashboard
- Supports OCR for medical documents
- Can be designed for EHR/FHIR integration

## Technology Stack

- Frontend: Next.js / React
- Backend: Node.js / Python
- AI/NLP: Large Language Models
- Database: PostgreSQL
- ORM: Prisma
- Speech-to-Text: Multilingual STT
- OCR: Optical Character Recognition
- Styling: Tailwind CSS
- Deployment: Vercel

## Safety Approach

MediKiosk is designed as an AI-assisted documentation and clinical intake system.

AI-generated information and suggestions are intended for professional review. The doctor remains responsible for final clinical decisions.
